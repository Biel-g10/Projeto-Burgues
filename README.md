## 🛠 Tecnologias
- HTML5
- CSS3
- JavaScript (ES6+)
- DOM Manipulation
- Array Methods (map, filter, reduce)


---

## ✨ Funcionalidades

✅ Listagem dinâmica de produtos  
✅ Carrinho inteligente com quantidade  
✅ Adicionar e remover itens  
✅ Cálculo automático de subtotal e total  
✅ Promoção automática com desconto  
✅ Filtro de opções veganas  
✅ Cálculo total usando reduce()  
✅ Atualização dinâmica da interface

---

## 🧠 Conceitos praticados

Neste projeto trabalhei conceitos importantes de desenvolvimento front-end:

- Manipulação de estado com arrays
- Lógica de negócio
- Renderização dinâmica no DOM
- Métodos map, filter e reduce
- Organização de funções
- Estruturação de componentes em JavaScript
